# 上网调研

1. 把问题拆成 2～4 个具体的搜索词。技术问题用中文和英文都搜一遍，英文结果通常更多。
2. 用 `websearch` 搜索，挑最相关的 3～5 个结果，用 `webfetch` 读原文。只看搜索摘要不算查过。
3. 优先看官方文档、GitHub 仓库和 issue、作者本人的文章。注意发布日期，旧答案可能已经过时，以版本号对得上的为准。
4. 页面要点击、登录，或者内容靠 JavaScript 才显示时，用浏览器工具（`browser_navigate` 后用 `browser_snapshot` 读取）。
5. 回复：先给结论，再列关键依据，最后附上来源链接。查不到就直说，不要编。
